Find the DialogContent component for the "Tegels aanpassen" modal and apply the following changes:

1. Set a maximum height using `max-h-[80vh]` (not 100vh)
2. Add `overflow-y-auto` to the scrollable content area inside the modal (the tile lists), NOT to the entire DialogContent
3. Keep the footer (Annuleren + Opslaan buttons) OUTSIDE the scrollable area so it is always visible at the bottom
4. Add `overflow-hidden` to the DialogContent itself so it respects rounded corners while scrolling

The result should be a modal that:
- Is never taller than 80% of the visible viewport height
- Has a scrollable middle section (active tiles + available tiles list)
- Always shows the footer buttons without scrolling
- Stays visually centered and does not feel cramped
