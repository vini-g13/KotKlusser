## Goal
Update the frontend to work with the new refresh token system. The access token stays in React memory (never in localStorage). The refresh token is received from the backend and stored in localStorage (since httpOnly cookies require additional backend CORS setup). Build automatic token renewal and a session-expired screen.

## Change 1 — AuthContext

Find the AuthContext file. Currently it stores a single token. Update it to:

1. State:
   - `user` — user object (keep existing)
   - `token` — access token in memory only (keep existing, do NOT store in localStorage)
   - `refreshToken` — stored in localStorage as 'refresh_token'

2. On app load (useEffect):
   - Read 'refresh_token' from localStorage
   - If it exists, call POST /auth/refresh with { refresh_token } 
   - If successful: set token and user from response, continue normally
   - If failed (401): clear localStorage, set user/token to null (session expired)

3. Update the login function:
   - After successful login, save response.refresh_token to localStorage as 'refresh_token'
   - Set token (access token) in memory state only

4. Update the logout function:
   - Call POST /auth/logout with { refresh_token: localStorage.getItem('refresh_token') }
   - Clear localStorage ('refresh_token')
   - Set user and token to null

5. Add a new function: refreshAccessToken()
   - Reads refresh_token from localStorage
   - Calls POST /auth/refresh
   - If successful: updates token in state, returns new token
   - If failed: clears localStorage, sets user/token to null, sets a new state variable `sessionExpired` to true

6. Add `sessionExpired` to context state (default false) and expose it + a `clearSessionExpired` function (sets it back to false)
