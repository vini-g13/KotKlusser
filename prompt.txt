This is a new public pricing page for KotKlusser, a Belgian student housing maintenance ticketing platform. Build it to match the existing site style exactly — dark background, indigo accent, Framer Motion animations, LandingNav and LandingFooter.

--- STYLE REFERENCE ---
- Background: bg-[#0B0A14], cards: bg-[#161425], elevated: bg-[#1C1A2E]
- Borders: border-white/5, hover: hover:border-indigo-500/30
- Text: text-white (headings), text-slate-400 (body), text-indigo-400 (accents)
- Font headings: font-['Outfit'], body: Inter
- Accent color: indigo-500 / indigo-600
- Animations: Framer Motion fadeUp pattern used across the site:
  const fadeUp = (delay = 0) => ({ initial: { opacity: 0, y: 20 }, animate: { opacity: 1, y: 0 }, transition: { duration: 0.5, delay } })
- Buttons: bg-indigo-600 hover:bg-indigo-700 text-white for primary; border-white/10 text-white for ghost/outline
